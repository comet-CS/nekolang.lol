NekoLang Documentation

Running Syntax UI Network File Ops Modules Examples

1. Running NekoLang

python nekolang_interpreter.py <file.neko>

Make sure Python 3 and requests library are installed.

2. Language Syntax

Variables

let x = 10;
let name = "Neko";

Printing

print x;
print "Hello, " + name;

Functions

fn greet(person) {
    print "Hello, " + person;
}
greet("Alice");

Conditionals

if x > 5 {
    print "x is big";
} else {
    print "x is small";
}

Loops

while x > 0 {
    print x;
    x = x - 1;
}

3. UI Functions

All UI functions are under the ui namespace.

Window

ui.window("My Window", 600, 400, "#222222");

Label

ui.label("Hello", color="white", bg="#333333", clicked=callbackFunction);

Button

ui.button("Click Me", color="white", bg="#444444", clicked=callbackFunction);

Input

let inputField = ui.input("Type here...", color="black", bg="white");

Show

ui.show();

4. Network Requests

GET Request

let response = net.get("https://example.com");
print response.status;
print response.text;

POST Request

let response = net.post("https://example.com", "data=hello");
print response.status;
print response.text;

5. File Operations

let content = file.read("test.txt");
file.write("output.txt", "Hello, world!");

6. Built-in Modules

  • math → standard math functions
  • neko.secret() → launches Snake game
  • neko.magic_8ball() → Magic 8-Ball easter egg

7. Examples

UI + Network

ui.window("Example", 400, 300)
let btn = ui.button("Fetch Data", clicked=function() {
    let res = net.get("https://example.com");
    print res.status;
})
ui.show();

Magic 8-Ball

neko.magic_8ball();
